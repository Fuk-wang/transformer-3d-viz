MLP 前馈网络 768→3072→768

6×768×W₁→ 6×3072GELU→ 6×3072×W₂→ 6×768

注意力负责让 token 之间交换信息；MLP 负责让每个 token 自己想清楚。 它逐位置作用、不跨 token，先把维度撑大 4 倍（能表达更复杂的组合），过 GELU 非线性， 再压回 768。每层两个权重矩阵：768×3072 与 3072×768， 约 4.7 M 参数 —— 约占一个 GPT-2 层参数的 2/3。

下一 token 概率 softmax(logits)

最后一个位置的向量乘上词表矩阵（50257×768）得到 logits， 再 softmax 成概率。取概率最大的那个，就是这一步「吐出来」的词。

长廊怎么读 弧 = 注意力

画面是一条门廊：一道门 = 一层（① 嵌入 → ②③④⑤ 四块 Decoder → ⑥ 输出/logits），门一道套一道往深处退， 走一步就多开一道门。
每颗发光珠是一个 token 在该层的向量（不是文字，是 768 个数），珠子串在柱子上就是残差流； 门里那几条拱起来的弧是注意力，线越粗越亮，说明这一层越在看那个词；每块里柱子还会分叉成 12 条头轨， 对应 GPT-2 的 12 个注意力头（右侧可点 H1–H12 切换，亮的那条是当前选中的头）。

Transformer 与 GPT：到底是什么关系

一句话：Transformer 是 2017 年那篇论文给出的整体架构；GPT 是其中「只用 Decoder 那一半」的堆叠。

① Transformer 原版（Encoder–Decoder）

输入嵌入 + 位置编码
Encoder 块 ×N
自注意力（双向，不掩码）+ FFN
↕ 编码器输出（每个位置的上下文向量）
Decoder 块 ×N
掩码自注意力 + 交叉注意力 + FFN
线性层 + softmax → 输出词分布
两部分都在：Encoder 先把整句读进去（双向看），Decoder 一边看已生成的词、 一边回头查 Encoder 的输出。典型任务是翻译：输入一整句，输出另一整句。

② GPT（Decoder-only）

token 嵌入 + 位置编码
Decoder 块 ×N
掩码自注意力 + 残差/LayerNorm + FFN
… 重复 N 次（GPT-2 small：N = 12）…
最后一层 LayerNorm
线性层（→ logits）+ softmax → 下一个词
没有 Encoder、没有交叉注意力：只有 Decoder，砍掉一半。 因为只做「预测下一个词」，输入和输出本来就是同一串文本，不需要两个网络。 于是它天生自回归：预测出 1 个词 → 接到句尾 → 整句再跑一遍 → 再预测。

对照表

  • Encoder：双向自注意力（每个词能看到左右两边），没有掩码。GPT 里没有。
  • Decoder：掩码自注意力（每个词只能看到自己和左边），这是自回归的关键 —— 保证训练时不会「偷看答案」。
  • 交叉注意力：Decoder 去查 Encoder 的输出。GPT 里没有（没有另一个序列可查）。
  • GPT = Decoder 块堆叠 + 词表投影，参数几乎全在 Decoder 块里（每层约 7 M，12 层约 85 M，加上嵌入共 124 M）。
  • 自回归语言模型：P(下一个词 | 前面所有词)。生成 = 反复调用自己，每次只产出一个 token。

怎么读这个页面

给第一次打开的人：3 分钟上手。两种视图讲的是同一件事，换着看最省力。

两套视图（底部「框图 / 解剖」切换）

  • ① 结构框图：网络像一摞抽屉。数据是一个张量方块，一格一格往上搬，到哪个模块哪个模块亮。 适合看清「顺序」：嵌入 → Decoder×4（⋮×12）→ 最终 LayerNorm → logits。
  • ② 向量解剖：把同一个过程的内脏摊开。每颗发光球是一个 token 的向量， 竖着的金线是残差流，层与层之间的弧线是注意力（越粗越亮 = 权重越大）， 弧线围成的扇形就是「谁在看谁」。适合看清「token 之间怎么交换信息」。
  • 两套视图共用同一套 12 步叙事和同一批演示数值，所以任何时候按「上一步/下一步」都是同一步。

画面上的东西是什么

  • 方块 = 张量（一批数字）。底下一排是 token，每个 token 会变成一条 768 维向量。
  • 大盒子 = 网络模块；琥珀色发光 = 数据此刻正在这里被计算，右侧面板同时写出它在算哪个矩阵。
  • 青金石蓝的小方块 = 正在搬运的那个张量。它一格一格跳，没有粒子拖尾 —— 这样能看清数据走到哪。
  • 当前这块 Decoder 会被拉开，露出 LayerNorm → 掩码注意力 → Add&Norm → MLP → Add&Norm 五个子模块和两条残差旁路。
  • 长廊里珠子只区分两种：金色=提示词里的 token，石绿=模型新生成的 token。
