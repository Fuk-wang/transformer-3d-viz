两套视图分别讲什么
-----------------------------------------------------
① 结构框图：
    token 张量方块 → 嵌入 + 位置编码 → Decoder 块 ×4（⋮ 实际 ×12）
      → 最终 LayerNorm → logits → softmax → 下一个 token → 接回句尾再来一遍

    数据是**一个方块**（0.4 见方），一格一格往上跳，不散、不拖尾、没有粒子流；
    它到哪个模块，哪个模块亮，右侧面板同时写出内部在算什么矩阵。
    单个 Decoder 块会像抽屉一样拉开，露出五个子模块 + 两条残差旁路：

      ① LayerNorm → ② 掩码多头自注意力（H_i = softmax(Q_iK_iᵀ/√d_k + M)V_i）
        → ③ 残差相加 + LayerNorm → ④ MLP(768→3072→768, GELU) → ⑤ 残差相加 + LayerNorm

    五块都描了金边，注意力矩阵贴在 MHA 正面：深色底板 + 5×5 格子，
    低权重石青、高权重金、被掩码的右上角暗朱砂。

② 词珠长廊（照第一版的「门廊」重做的）：
    一条纵深走廊：一道门 = 一层 —— ① 嵌入 → ②③④⑤ 四块 Decoder → ⑥ 输出/logits，
    门一道套一道往深处退，走一步往里多开一道门；离观众最近的是嵌入门。
    每颗发光珠 = 一个 token 在该层的 768 维向量，按词性分色（金 = 名词/术语，
    石青 = 虚词/动词，石绿 = 标点/数字/新词）；珠子串在柱子上 = **残差流**。
    门里每根柱子分叉成 4 条**头轨**（= 画出来的 4 个代表头），轨道上拱起的**弧** = 注意力：
    越粗越亮权重越大，颜色从石青 → 金 → 朱砂。只画当前这一块的弧，四块同时画会糊成一团。
    柜内那层暖光（门内玻璃面 + 门顶灯带）是 v1 的「展柜」感 —— 只在柜内发光，
    柜外仍是深空星野 + 地面藻井 + 三圈涟漪，所以不会整屏糊成米黄。
    画面下沿压着一条大公式（SCALED DOT-PRODUCT ATTENTION），走到第 5 步时出现。
    右侧「查询词」可以选一个词，只看它把注意力投给了谁。

数据来源：真跑了一遍 GPT-2 small

页面上 12 层 × 12 头的注意力权重、5×5（以及接一个词之后的 6×6）矩阵、下一词概率分布，
全部来自本地对 **GPT-2 small（124M，12 层 / 12 头 / d=768）** 的一次完整前向：

- 权重用 `np.frombuffer` 直接读 `model.safetensors`（8 字节头长度 + JSON 头 + 裸 float32），
  前向只用 LayerNorm、矩阵乘、softmax、GELU —— **numpy 就够，全程没装 torch**。
- `huggingface.co` 直连不通，`hf-mirror.com` 通（548 MB，curl 55 秒）。
- 交叉验证（三条同时成立，基本排除实现 bug）：

  | 探针 | 结果 |
  |---|---|
  | New York is a city in the United States of | America 0.9566 |
  | 1, 2, 3, 4, 5, | 6 0.9095 |
  | Water is made of hydrogen and | oxygen 0.4641 |
  | 因果掩码右上角 | 全部恰为 0.0 |

- 演示句改成英文 **"GPT is a language"**（5 个 token）。中文提示词在 GPT-2 的字节级 BPE 下是
  20 个 token，每个汉字碎成 2–3 个字节片段、解码是乱码，5×5 就没了。
  顺带成了教学点：连 "GPT" 都被切成 `G` + `PT`。
- 页面里已经**没有任何构造出来的注意力分数**，GEN_PLAN 手写概率表也删了，
  概率条直接读模型的下一词分布（第一名 " that" 只有 18.0%，前 6 名合计 47%）。

真数据顺带推翻了一件事：144 个头里三分之二都在往第一个 token 倒注意力（attention sink），
第 7 层整层平均 92.3%、12 个头里 9 个几乎只看首词 —— "每个头各管一摊"只在第 0 层成立。
这条比原来那套整齐分工更值得讲，也是 StreamingLLM / KV Cache 驱逐策略的现实依据，已写进 STEP 05。
右侧面板一次性给出 12 个层按钮、12 个头按钮、12 根「每层首词占比」柱，都能点。

外场涡环（v1 的轨道感，减量版）
-----------------------------------------------------
背景那 6 道金色椭圆轨道是 v1 的语汇搬回来的，但按这版密度做了减法：

- 数量 6 道（v1 约 12 道）；透明度 0.10–0.13（v1 约 0.18–0.22）。
- 只在模型后方：环上落在柜子/机架包围盒里的线段、以及跑到模型前面的那半边，
  逐段剔掉 —— 所以它在柜子后面绕，不穿进模型区也不压门廊。
- 语义：半径与亮度跟着当前层的 attention sink 强度走（sink 越高，环越往里收、略亮）。
  切层时能看出来：L1（0.389）环最松，L8（0.923）收得最紧。
- `?bg=off` 关闭，键盘 `B` 切换。

交互
-----------------------------------------------------
- 下一步 / 上一步（← →）· 播放/暂停（空格）· 重来（R）
- 框图 / 解剖切换（M，或底部两个按钮，或右侧「现在看的是哪种图」里的按钮）
- 2D / 3D（2 / 1）：2D 是近正交的正面视图，模块与球排成平面示意；3D 能看见残差旁路绕在侧面深里
- 跟随（F）：相机自动对准当前模块/台阶；关掉后鼠标拖动转视角、滚轮缩放
- 注意力头 H1–H4（Q / E 循环；真实模型是 12 头，画面画 4 个代表）：框图里的矩阵网格、长廊里的弧线、右侧数值表三处同步
- 查询词（只影响解剖视图）：全部 / 每个 token 一个按钮
- 架构总览：Transformer 的 Encoder/Decoder 与 GPT（decoder-only）的对照表
- 说明：给第一次打开的人的导读
- 左侧 12 步可点跳转

想改哪里（搜「★」）
-----------------------------------------------------
- `PROMPT_TOKENS` / `GEN_PLAN` —— 换提示词、换要生成的句子（概率条一起换）
- `NBLOCK`（画几块实体，默认 4）/ `REAL_LAYERS`（12）/ `NHEAD`（4）/ `DK` / `DMODEL` / `DFF`
- `STAGES` —— 12 步的标题、讲解、形状流、亮哪个模块
- `GATE_OF_STAGE` —— 12 步分别走到第几道门（0 = 嵌入，1–4 = 块，5 = 输出）
- `STG` —— 长廊：词间距 2.02 / 门间距 3.95 / 门半高 2.90 / 珠半径 0.42
- `HYN` —— 4 个头在门平面上的高度 ±1.18 / ±0.40
- `<style>` 顶部 `:root` —— 整套敦煌配色（石青 / 金 / 朱砂 / 石绿 / 纸色）
